# paper-pure

Own the stack on a reMarkable Paper Pure. The OS stays frozen, sync goes to a self-hosted server, and mods are proven in an emulator before they ship to the tablet over the air.

This one repo holds the config, mods, apps, server, and docs.

- [Desiderata](docs/desiderata.md): what we want, ranked, and what we say no to.

First move: stand up the full-OS emulator and run a trivial AppLoad "hello" app in it.
